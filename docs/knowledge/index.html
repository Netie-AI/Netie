This page runs a local cleaning job on a messy invoice extract: trim names, map vendor aliases, parse MYR amounts and calendar dates, require invoice + amount + date + known vendor, drop exact duplicates, and park the rest as exceptions. Vendor totals and answers come only from the cleaned table, with the raw row IDs that produced each result.

Synthetic records only. No upload, model, warehouse, or customer file. Refreshing resets the job. This is the cleaning-and-citation pattern sold as scoped work, not a production ETL platform.
