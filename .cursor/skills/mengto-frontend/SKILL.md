# Meng To frontend (Netie)

Upstream: https://github.com/MengTo/Skills (MIT, Meng To). Profile: https://github.com/mengto

This is the Netie load point. Do not paste the whole 100-plus skill tree into one chat. Open the one matching skill, then build.

## Load this first

1. `landing-page` for a one-offer landing. Local copy: `.cursor/skills/mengto-landing-page/SKILL.md`
2. `build-awwwards-quality-sites` only when the owner asked for a motion-led or cinematic site. Clone MengTo/Skills and open `agent-skills/web-design/build-awwwards-quality-sites/SKILL.md`
3. GSAP / Three.js / Tailwind skills in that same `agent-skills/web-design/` folder, one at a time.

## Netie constraints

- Buyer facts only. No fake logos, fake reviews, or invented metrics.
- Show the owner before send or before a public host.
- Traditional website first. Marketing agent and DMS are a later step. Cite `.cursor/skills/offer-ladder/SKILL.md`.
- Pair with `.cursor/skills/scroll-craft-landing/SKILL.md` when scroll is the timeline.

## Download when needed

```bash
git clone --depth 1 https://github.com/MengTo/Skills.git
```

Then open only the matching `agent-skills/web-design/<name>/SKILL.md`. Do not load game-development skills for a factory landing.
