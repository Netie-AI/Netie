# Proposal

Use for Truelancer, Fiverr, Upwork, email bids, and hire pages.

## Before you write

1. Read `STATUS.md` and `.cursor/AGENTS.md`.
2. Open the listing. Copy budget, skills, client paid/posted, and the actual ask.
3. Screen: skip SEO, data-entry, "pay a deposit", off-platform payment, or work you cannot evidence.
4. Paid-to-posted far below 1 is a warning, not an auto-skip. Bid the listed price. Extra scope is a written change request.

## Shape

- What you will do in their words
- What the bid covers, in artifacts they can open
- What it does not cover
- Proof URLs that already return HTTP 200 (netie.ai/hire, /hire/ops, /aim, GitHub Netie-AI)
- One question so you start on the right files
- Bid and days. All talk on the platform.

## Never

- Invent AirGPT/DMS screenshots you did not open
- Send the bid by Gmail when the platform has a Send Proposal button
- Store passwords in git
- Spray a bid on mismatch work
