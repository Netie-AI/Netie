# Offer ladder (direct English)

Say the work in this order. Do not dump the whole ladder in a first mail unless they asked what else you do.

## 1. Traditional web development

We build a better landing page, shop page, or factory page from their real copy and photos. Ordinary website work. RM 500 unlocks the first draft. After they see it, the rest of the page work is quoted in writing. Usual full landing band is RM 1,000 to RM 5,000. Honor any lower price already named in that thread.

Build the page with `.cursor/skills/scroll-craft-landing/SKILL.md` and `.cursor/skills/mengto-frontend/SKILL.md` when it is a real landing, not a Coming Soon fill-in.

## 2. Marketing agent

A marketing agent that tracks campaigns, leads, and what was sent. It does not replace the website. It runs after the site exists.

## 3. Database and document system

A database management system that can grow with them. DMS-class document store. Public proof is the invoice workbench and ops board on https://netie.ai/hire/ not a private Jumpwin file.

## 4. Agentic operations

Agents that work in that database: tracking marketing, follow-ups, and the daily ops so more of the business can run without a person copying cells. Quoted after written scope. If it is one internal workflow, RM 20,000 operations checkout can follow that scope. Do not invent a new Stripe product.

## First mail

Only step 1. One sentence. RM 500 for the first draft. No Stripe link.

## If they ask how much for the proposal

Write the proposal. Show the owner. Do not send. Cite `.cursor/skills/show-before-send/SKILL.md`.
